# Proyecto_SQL
Realización de proyecto del módulo SQL en el que se realizan 64 consultas sobre la base de datos "Proyecto_shakila". La herramienta utilizada es DBeaver a través del motor postgres. El diagrama de relaciones entre tablas se encuentra en el fichero "Proyecto_shakila_EsquemaBBDD".

DESCRIPCIÓN: 
El proyecto contiene 64 consultas que han buscado información dentro de las tablas tanto de forma individual como combinada a través de relaciones entre tablas, utilizando principalmente los siguientes comando en SQL: select/from, inner join, left join, with, temporary table, group by, order by, where, having, funciones de agrupación (suma, contar), concat, limit, offset, avg. 
Se adjunta el script "SCRIPT_entregaSQL_AntonioLinares" con las 64 consultas, numeradas de menor a mayor, e indicando en el enunciado cuál es el objetivo que tiene cada una de las consultas. Todas las consultas ofrecen la visualización final del resultado.

ESTRUCTURA: 
Proyecto_shakila_EsquemaBBDD #Imagen con todas las tablas de la base de datos y la relación que tienen las mismas en base a primary y foreing keys.
SCRIPT_entregaSQL_AntonioLinares #Script con las consultas realizadas sobre la base de datos "BBDD_Proyecto_shakila".
README.md #Descripción del proyecto

REQUISITOS: 
- Es necesario tener instalado el programa Dbeaver y el motor Postgres.
- Es necesario tener en Dbeaver la base de datos "BBDD_Proyecto_shakila".

CONCLUSIONES: 
- Las consultas han permitido extraer información filtrada y ordenadas de las tablas.
- Se han incluido consultas relacionando varias tablas y agrupando por campos para poder simplificar el análisis de la información.
- Se han realizado consultas incluyendo subconsultas para simplificar el filtrado de información.
- Se han realizado consultas incluyendo tablas temporales que han permitido simplicar el diseño de las mismas.
- Las consultas resultantes de cada punto, han permitido obtener una información más completo y simplificada de las 15 tablas de partida que forman la BBDD.
